# 📦 Warehouse Dashboard

Interactive Warehouse Dashboard built using HTML, CSS, and JavaScript.

## 🚀 Features

- 📊 KPI Dashboard
- 📈 Daily Order Trend
- 👷 Productivity per Picker
- 🎯 Target vs Actual
- 🚨 Error Monitoring
- 📦 Inventory Accuracy
- ⏱ Lead Time Monitoring
- 🏆 Top Performer Ranking

## 🛠 Technologies

- HTML5
- CSS3
- JavaScript
- Chart.js

## 📋 Dashboard Preview

The dashboard will display:

- Total Orders
- Completed Orders
- Pending Orders
- Productivity
- Accuracy
- Picking Errors
- Lead Time
- Daily Charts
- Monthly Charts
- Team Performance
